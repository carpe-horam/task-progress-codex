# 打开任务进度浮窗

使用现有 Task Progress 账本，不初始化新任务、不复制计划。默认打开当前会话正在跟踪的任务，不能因为未指定参数就选最近更新的其他任务或上次查看的任务。

先从本会话最近成功的 Task Progress 回执或已恢复的工作上下文取得 `session_id` 和 `task_instance_id`。已有准确实例身份时复用；仅有会话 ID 时，调用 `get_progress(view="overview")` 读取当前实例 ID。用户明确指定其他任务时，以用户指定为准。

执行随附脚本，传入已确认的两个 ID；将 `<skill-dir>` 替换为本文件的真实目录：

```sh
python3 "<skill-dir>/scripts/open_progress.py" --session "<session_id>" --task-instance "<task_instance_id>"
```

命令直接打开 macOS 原生窗口，默认黑色并置顶。左侧列出本机后台服务中的当前、并行及历史任务；右侧复用原版面板。支持单任务查看与最多8项平铺，只有选中卡片可以滚动内部内容。置顶、窗口大小和主题从左栏操作。侧栏默认展开，缩小窗口不自动折叠，由用户手动收起和展开。关闭窗口不停止任务。

ID 必须来自成功回执或本会话已恢复的上下文，不能使用宿主聊天 ID 或猜测值，也不能扫描其他会话来代选。只有当前会话没有可确认的 Task Progress 身份，或用户明确要求只打开任务总览时，才省略两个参数打开列表，并说明没有定位到本会话。已确认的任务读取失败时如实报告，不静默改选其他任务。

## 服务与平台

需要有桌面的 macOS、Python 3 和 Xcode Command Line Tools。原生窗口首次编译后缓存。其他系统或远程无桌面环境不改用浏览器，也不声称窗口已在用户电脑显示。

服务尚未启动或版本过旧时，随插件安装且能找到同包服务代码的脚本加 `--ensure-service`，用该包安装或更新并启动本机服务。独立复制的 Skill 不含后台服务，需先安装 Task Progress；已有服务可直接连接。`--port`、`--state-dir` 仅供已明确的隔离服务设置使用，不猜凭据目录或扩大监听范围。

`--check` 只检查服务访问与任务定位，不创建窗口。正常命令返回 `window_opened`、实际原生进程ID与 `always_on_top`；窗口回执只证明窗口已创建，不能据此声称特定任务已经加载或执行完成。服务管理凭据和内部访问链接不得输出、存入长期记忆或公开发布。

## 使用边界

只在用户要求打开或重开时执行，不随每次状态更新反复创建窗口。窗口独立读取最新数据，查看与切换不改变正在执行的任务或前台请求。任务来源限于同一本机 Task Progress 后台服务，其他工具的独立数据源不会自动汇入。

导出按钮使用原版面板生成 Excel 与 HTML，由原生窗口确认保存到 `Downloads/Task Progress Exports`。不要把打开窗口当作任务验收或清理依据。
