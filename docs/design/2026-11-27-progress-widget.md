# 原生任务进度浮窗

CLI 和 Agent 使用 `progress_widget.py` 或 `open-progress-widget` Skill 打开 macOS 原生浮窗，默认黑色并置顶。窗口关闭不停止后台任务。

## 界面与交互

- 左栏集中放置任务列表、搜索、筛选、单任务/平铺切换、置顶、窗口大小及主题控制。右侧只展示进度。
- 侧栏默认展开，任何窗口宽度与紧凑模式都不自动收起。用户点击“收起任务列表”后隐藏，再点击左上角入口展开；窗口缩放与任务切换保留手动选择。
- 单任务直接展示完整页面；平铺最多 8 项，随可用宽度调整列数。只有选中卡片可滚动和操作内部页面，未选中卡片上的滚轮用于浏览整个平铺区。点选卡片只改变选中项，不触发其内部按钮。
- 卡片外层只保留选中、放大与移出控制，任务标题只在原版进度页出现一次。
- 右侧从真实 `resources/read` 取得现有 `app.html`，通过沙箱 iframe 和协议适配器复用原有任务树、矩阵、详情、历史与报告生成，不另写进度渲染器。

## 数据与原生桥接

`widget_store.py` 只读发现同一本机共享服务中的当前、并行及有明确身份的历史实例，按任务实例固定快照，不跟随 Agent 的前台任务切换。只读查看不占用已有宿主的全屏视图租约。

已认证的 `POST /widget/open` 创建 12 小时有效的只读目录凭据，窗口内部使用 `/widget/session`、`/widget/catalogue` 与 `/widget/rpc`。凭据与服务管理凭据分离；桥接仅允许读取原版 UI 资源和任务快照，不开放修改任务接口。Host/Origin 限定同一回环地址。命令不输出私有链接。

`ProgressWidget.swift` 使用 AppKit 与 WKWebView，提供实际窗口级别切换、紧凑/还原与导出保存。仅顶层同源页面能调用原生桥接；导出验证 Excel/HTML 格式、配对文件名和大小，保存到 `Downloads/Task Progress Exports`，不覆盖已有文件。

## 使用与验证范围

```sh
python3 plugins/task-progress/progress_widget.py --ensure-service
```

Skill 默认从当前会话的成功回执恢复身份，并传入 `--session` 与 `--task-instance` 精确定位，不选最近更新的其他任务或上次查看项。仅没有可确认的任务身份或用户要求总览时省略定位参数。`--check` 只核对服务访问，不打开窗口。首次需要 Python 3 与 Xcode Command Line Tools 编译原生程序，之后使用缓存。无桌面或其他操作系统不会改用浏览器。

使用临时账本和真实 HTTP 服务验证目录、实例隔离、实时更新、原版资源、8 项上限、选中滚动、手动侧栏、明暗主题和 Excel/HTML 下载。macOS 实际窗口另行验证创建回执、置顶级别、紧凑尺寸及两份报告落盘；这些与无头 Chrome 的页面回归分开记录。

仅汇集接入同一本机服务的 Task Progress 数据，不自动汇集其他 Agent 的独立账本或 Cindy KV 数据。不部署公网服务，不改发布版本；本地源码验证不代表已安装或发布升级。
