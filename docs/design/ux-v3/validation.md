## 未完成的验证

内置浏览器拒绝 `file://` 本地原型导航，原因是 URL 协议安全策略不允许该协议。本次没有通过其他浏览器、临时服务或间接执行绕过该限制。

因此以下项目均不能声称通过：

- 新 HTML 在实际浏览器中的桌面/360px 布局、滚动和容器查询。
- 原生表单选择、弹窗关闭后的焦点、键盘展开任务和读屏播报。
- 200% 文本缩放、长标题/长证据、真实宿主深浅主题映射。
- 真实 MCP 请求、暂停/停止反馈、iframe 生命周期和乱序数据更新。
- 浏览器下载及导出文件的实际打开。

原型提供可直接打开的 `index.html`，相邻 `styles.css` 和 `prototype.js` 需一起保留。当前原型仅以 Markdown/JSON 演示导出范围；HTML/Excel 为后续产品实现项。

## 语义与本轮修正

- 修订 5 的单项详情包含自身结论、产出、未完成事项和检查记录。根任务内保留整体说明并定位子项；不另建结果分区。已完成节点的文件和检查有不同内容与来源，演示数据始终明确标识。

- 修订 4 曾将入口更名为“任务结果”；修订 5 按用户反馈完全移除该独立区域，内容归入对应任务项。修订 2 静态图属于旧稿，当前结构以 HTML 交互稿为准。

- 恢复原版两个同级折叠区及名称：当前任务的历史计划 / 历史任务；旧计划在当前任务下按轮次展示，归档任务按会话展示。
- 历史任务示例换成与坐标轴修复不相关的读书笔记、下载目录清理；旧任务自己的旧计划仅嵌套在该旧任务内。
- 本轮重新运行 14 个可选场景及 submitted 内部状态的离线模板检查；历史归属、原位展开和导出范围通过检查。新任务归档的真实后端流程属于 E6，未在此演示中实现或验证。

- 暂停后执行报告已返回，不意味着该叶任务已经验收；暂停态仍保留 4 项已解决结果，恢复不回退计数。
- 未知执行的最近进展不能写“当前活动已确认”；改为明确指出页面读取成功但执行观察未更新。
- 取消项在进度条上使用中性色，区别于已解决项；摘要显示已取消数量。
- 待用户输入的第一项工作直接说明等待选择，不错误声称已经解决的前驱仍阻塞。
- 多层操作弹窗保留原始触发元素，避免用已经被替换的菜单按钮作为关闭后的返回目标；仍待真实浏览器确认。
- 撤回四页签、大概览和只展示当前项；全部直接子任务默认可见，详情原位展开。
- 已暂停且无在途执行时，取消剩余任务不显示虚构的“1 项仍在停止”；存在执行时继续等待真实终止。
- 旧版 56 个视图组合的检查不作为本修订版验收依据；本轮重新检查任务树与状态语义。

设计稿可以用于信息架构和状态流程评审。进入实现阶段后，按 UX 文档的 U01–U12 及开发计划的 T/E 用例完成真实宿主验收，不能把本记录替代为产品上线证明。
