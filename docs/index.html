01

在终端安装

codex plugin marketplace add carpe-horam/task-progress-codex
codex plugin add task-progress@task-progress-codex

安装后重启 Codex。首次连接会安装或更新本机共享后台服务。

02

给它一个真实任务

用 Task Progress 帮我完成 [描述你的任务]。先规划步骤和验收标准，持续更新进度，遇到阻塞说明原因，最后检查结果并保留证据。

随时说「打开任务进度」，查看任务面板。

安装前需要什么？+

需要支持插件与 stdio MCP 的 Codex、可通过 python 启动的 Python 3，以及支持 MCP Apps 的客户端来显示交互面板。

macOS 使用 LaunchAgent；Linux 需要可用的 systemd 用户会话；Windows 使用当前登录用户的任务计划程序。

04 / A FEW GOOD QUESTIONS

开始之前，
你可能想知道。

它会替我自动执行任务吗？+

Codex 负责规划、执行和协调；Task Progress 保存并展示状态、依赖和证据。插件本身不会唤醒或控制宿主 agent，也不会自动执行队列中的工作。

我的任务数据保存在哪里？+

任务数据保存在本机，各个会话分别记录进度。你可以通过面板导出 Excel 和 HTML 报告。

进度 100%，就代表全部完成了吗？+

百分比表示已解决且验收完成的叶任务比例。子任务全部完成后，仍需要主会话对整体结果做综合验收。

适合用在哪些任务里？+

功能开发、Bug 排查、重构和多智能体协作，都适合用它跟踪多步骤工作。简单问答不需要建立任务树。
