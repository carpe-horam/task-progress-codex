# Task Progress 0.2.0 按需进度与界面验收

本次修复覆盖任务进度消息过大、默认界面信息过密和显式查询粒度不足。版本保持 0.2.0；此前已有实现基线为 `e5bab2f76517415bb52952866e408b5f632e252e`。

## 最终行为

- 普通变更只返回操作回执及继续执行必需的身份、状态，不附整棵任务树、长摘要、证据或历史。`render_progress` 只返回面板启动身份。
- 模型显式调用 `get_progress` 才读取进度。默认 `overview`；可以选择指定任务、子树深度、分页记录、上下文或历史。`full` 和兼容的 `include_history=true` 显式返回目标 JSON 实例完整记录；并行实例历史按实例分别读取。旧 SQLite 仍是有界只读摘录，不能将它称为全库备份。
- 面板通过仅对 App 可见的 `get_progress_view` 自行读取和刷新。执行历史按需加载并绑定实例、计划轮次和版本；迟到的并行实例结果不会覆盖主任务。
- 上下文及执行验收详情默认折叠，移除任务行长摘要与重复计划信息，保留“角色 · 真实智能体 ID · 模型 · 思考强度”。展开叶任务后先看一份结果摘要，纵向执行、绑定、验收和证据字段继续折叠；并行任务仍是同级根节点。
- 部分读取明确标识分页和深度边界；分页可固定 `expected_state_revision`，状态变化时要求重新读取，防止混合版本。普通写入成功后无需为了确认回执再次读取全树。

## 验证

后端协议阶段 204 项 Python 测试通过，包含真实 JSON-RPC 小回执、查询层级、分页、旧数据完整性、验收和依赖保护；使用指导更新后再通过全部 205 项 Python 测试。13 组 Chrome 协议回归通过，覆盖启动、局部查询隔离、上下文折叠、真实执行者信息行、并行根、迟到历史、读取失败重试、空状态、SQLite-only、导出及视图租约。

用户随后澄清“展开任务主要展示结果摘要”，最终 App 在上述协议版本上做了展示顺序调整。对此追加通过队列/摘要、新协议、记录加载这 3 组相关 Chrome 回归；未重复运行不受影响的全部套件。最终 App 身份见 `summary-ui-manifest.json`，先前 13 组协议验证身份见 `ui-source-manifest.json`。7 项 hook 与 4 项公开 JSON-RPC 文档示例检查也通过。

浏览器使用真实隔离 Python 服务与安装的 Chrome，MCP Apps 父页面为模拟宿主。原生 Codex 验证使用桌面自带 CLI，两个临时 app-server 客户端均发现 23 个工具，并核对查询 schema、App-only 元信息和 0.2.0 页面资源；未创建聊天或模型回合。

固定合成压力场景中的 UTF-8 返回体积如下（不是 token 数）：

| 60 节点场景 | 修改前 | 修改后 |
|---|---:|---:|
| 默认查询 | 5,463,140 B | 1,329 B |
| 普通更新 | 5,454,001 B | 595 B |
| 展示入口 | 5,463,141 B | 496 B |
| 显式完整读取 | 5,463,171 B | 4,694,763 B |

合成数据包含较长派发、摘要、证据及重复尝试，用于验证放大风险，不能据此推算用户会话 token 数或原生展开耗时。完整读取的体积仍可能较大，这是显式选择的行为。未测量原生 Codex 消息展开延迟，不将载荷减小等同于已经测得原生卡顿消失。

## 证据与交付边界

[证据目录](2026-10-28-selective-progress-evidence/)保存各阶段源文件哈希、最终 205 项日志、13 组协议与 3 组最终摘要回归日志、原生独立服务发现结果、体积对比及截图。截图来自隔离测试场景，`summary-first-fields-collapsed.png` 展示最终摘要优先布局。此前误删执行者行的中间截图已移出交付证据，未用于本次验收。

测试源码身份以两个 source manifest 中的文件哈希为准。正式安装从提交后的 Git 内容建立稳定 marketplace 快照，安装与运行版核验记录另存本机 `Library/Application Support/Task Progress/install-records/<commit>/`，避免把未完成的安装当成已验证结果。

已加载的旧 iframe 不会自动替换 JavaScript，需重新打开面板加载新版资源；兼容旧快照是指新版 App 读取旧结果。历史会话中已经保存的大消息不会追溯缩小。本次不删除任务、历史或验收证据。
