## 验证与边界

- 通过 Python 标准库直接加载当前源码，将 `SESSION_DIR` 指向临时目录；合成任务未写入用户真实任务记录。临时测试使用 `review-fixture` 模型标记，不代表真实执行模型。
- TP-01～TP-07 用隔离调用复现；测试本身运行在本地，每条命令远低于 1 分钟且未命中 Dagu 白名单。
- 对照验证通过：普通兄弟依赖环被拒绝；旧 attempt 不能覆盖新 attempt；旧 task_instance_id 不能更新新任务；不同 session 相互隔离。
- 合成响应增长：每个任务 10 个子节点，每个子节点约 560 个中文字符的派发文本，累计 1/10/30 个任务时响应分别为 24,318 / 232,940 / 696,580 字节。该数据说明返回体增长，不是生产延迟或 token 开销的实测。
- 没有修改插件实现，没有提交、推送或发布。真实 MCP 宿主 UI、Excel 打开效果、Windows 安装均未做端到端验证。
