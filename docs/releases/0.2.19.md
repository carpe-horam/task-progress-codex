# Task Progress 0.2.19

发布日期：2026-11-06 · [完整更新记录](https://github.com/carpe-horam/task-progress-codex/blob/v0.2.19/CHANGELOG.md)

- **会话执行钩子**：加入工具执行前、返回后和子代理启动提醒，并在等待子代理返回和下一次用户输入时检查当前待验收汇总。提示遵循当前 actor 与任务绑定，不从工具参数、运行句柄或 transcript 推断任务结果。
- **汇总队列边界**：全实例待办和目标级 `synthesis_ready` 使用相同资格谓词。父节点已结束、已接受收尾、根级已移交关闭或当前盘点为 `obsolete` / `covered` 时不重复提醒；child actor 不读取实例级父级验收队列。
- **显式恢复与派发失效**：新增只读 `select_work_context`，支持当前 Codex actor 精确选择已有实例、epoch、task 和 attempt；attempt 结束或重试后旧派发关联失效。

## 安装或升级

```sh
codex plugin marketplace remove task-progress-codex
codex plugin marketplace add carpe-horam/task-progress-codex --ref v0.2.19
codex plugin add task-progress@task-progress-codex
```

首次安装可省略第一行。安装后重启 Codex 以加载新工具与 hook；现有任务数据保留。详见[安装文档](../installation.md)。
