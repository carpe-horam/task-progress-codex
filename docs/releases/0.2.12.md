# Task Progress 0.2.12

发布日期：2026-11-02 · [完整更新记录](https://github.com/carpe-horam/task-progress-codex/blob/v0.2.12/CHANGELOG.md)

- 同一任务实例中的主会话叶任务串行执行；已有任务运行时，后续主会话叶任务等待。子智能体任务可并行。
- 任务面板区分依赖已满足但等待主会话的任务，并指出正在执行的任务。
- 旧会话中已有的多个运行记录不会被自动更改；应核实实际工作并逐项收束。
- 修正服务管理测试中将 Linux 视为不支持平台的过时前提。

## 安装或升级

需要支持插件与 stdio MCP 的 Codex，以及 PATH 中可通过 `python` 启动的 Python 3。已有旧版本时：

```sh
codex plugin marketplace remove task-progress-codex
codex plugin marketplace add carpe-horam/task-progress-codex --ref v0.2.12
codex plugin add task-progress@task-progress-codex
```

首次安装可省略第一行。安装后重启 Codex，已打开的旧面板需重新打开。现有任务数据无需迁移。插件只约束其自身的状态登记，不会停止进程或自动派发任务。

## 验证范围

- 全量 Python 回归 278 项通过，覆盖串行启动竞争、恢复、重试、旧记录和子智能体并行。

- 原生 Codex 重启后的工具加载与后台服务切换仍需安装后验证；模拟宿主不替代该检查。
