# Task Progress 0.2.7

发布日期：2026-10-31 · [完整更新记录](https://github.com/carpe-horam/task-progress-codex/blob/v0.2.7/CHANGELOG.md)

- 缩短任务卡片上的当前尝试用时文案，例如“已用 1小时17分42秒”；已完成的尝试显示“耗时”。悬浮提示保留当前尝试和时间边界说明。

本版附带离线交互手册 `task-progress-0.2.7-guide.html`，使用本版界面和合成演示数据。

## 安装或升级

需要支持插件与 stdio MCP 的 Codex，以及 PATH 中可通过 `python` 启动的 Python 3。已有旧版本时：

```sh
codex plugin marketplace remove task-progress-codex
codex plugin marketplace add carpe-horam/task-progress-codex --ref v0.2.7
codex plugin add task-progress@task-progress-codex
```

首次安装可省略第一行。安装后重启 Codex；旧面板需重新打开。跨平台前提见[安装文档](https://github.com/carpe-horam/task-progress-codex/blob/v0.2.7/docs/installation.md)。
