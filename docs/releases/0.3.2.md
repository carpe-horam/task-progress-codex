# Task Progress 0.3.2

Cindy、Codex 和 DeepSeekRuntime 统一版本 **0.3.2**。

- 进度百分比放大至 24px 并加粗，增加多色渐变、细刻度和端点光晕。
- 进度条与数字同步缓动，进度变化时短暂扫光；支持连续更新、进度回退，刷新不重复播放。
- 新计划立即显示自身进度；减少动态效果时直接显示结果；读屏进度即时反映实际目标值。
- 暗色模式提亮渐变、收敛光晕，区分已完成进度与剩余轨道。

## Codex 安装或升级

```sh
codex plugin marketplace remove task-progress-codex
codex plugin marketplace add carpe-horam/task-progress-codex --ref v0.3.2
codex plugin add task-progress@task-progress-codex
```

首次安装可省略第一行。启动新的 Codex 会话加载新版。Cindy 从同一标签构建，详见 [构建说明](../../plugins/task-progress/cindy/README.md)。

源码 release 不附独立安装包；安装与运行时加载分别验证。
