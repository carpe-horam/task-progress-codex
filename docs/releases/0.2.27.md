# Task Progress 0.2.27

发布日期：2026-11-18

- 新增 Cindy 宿主适配，右侧栏支持会话切换、任务状态同步和五秒自动刷新。
- 可安全删除尚未执行、没有后继依赖的叶任务，并在修订历史保留原计划和原因。
- Cindy 安装包从共享源码及宿主差异生成，避免维护重复代码。

## 安装或升级 Codex 插件

```sh
codex plugin marketplace remove task-progress-codex
codex plugin marketplace add carpe-horam/task-progress-codex --ref v0.2.27
codex plugin add task-progress@task-progress-codex
```

首次安装可省略第一行。安装后重启 Codex，使插件重新加载。Cindy 本地插件版本为 0.2.54，构建方式见 [Cindy 构建说明](../../plugins/task-progress/cindy/README.md)。

## 验证与范围

- 服务端完整回归 371 项通过，客户端 29 个脚本通过；测试输出无警告。
- Cindy 原生侧栏验收覆盖状态筛选、切换会话与任务刷新、失败重试、删除、导出和重启恢复。
- Cindy 适配器中的代理身份由调用方提供，宿主不独立认证；测试未穷尽全部异常分支。
