# Task Progress 0.2.6

发布日期：2026-10-30 · [完整更新记录](https://github.com/carpe-horam/task-progress-codex/blob/v0.2.6/CHANGELOG.md) · [0.2.5 发布说明](https://github.com/carpe-horam/task-progress-codex/blob/v0.2.6/docs/releases/0.2.5.md)

- 将 `track-progress` 主技能整理为按步骤和条件执行的入口，规划、派发、验收、恢复及旧版 API 等细节按需加载。
- 增加子智能体模型和思考强度的选择建议；以宿主可用性和授权为准，并保留主会话的独立验收。
- 明确原子 root、阶段盘点提醒分页、提交后独立复核和并行任务执行者的规则，并补充后端回归覆盖。

本版附带离线交互手册 `task-progress-0.2.6-guide.html`，使用本版界面和合成演示数据。

## 安装或升级

需要支持插件与 stdio MCP 的 Codex，以及 PATH 中可通过 `python` 启动的 Python 3。已有旧版本时：

```sh
codex plugin marketplace remove task-progress-codex
codex plugin marketplace add carpe-horam/task-progress-codex --ref v0.2.6
codex plugin add task-progress@task-progress-codex
```

首次安装可省略第一行。安装后重启 Codex；首次连接会更新本机后台服务，旧面板需重新打开。跨平台前提见[安装文档](https://github.com/carpe-horam/task-progress-codex/blob/v0.2.6/docs/installation.md)。

## 验证范围

使用隔离任务数据运行技能派发协议、原子任务、阶段盘点和并行请求的针对性 Python 回归，以及技能格式和引用检查。这些检查不代表原生 Codex 桌面或 Linux、Windows 安装升级的端到端验收。
