# Task Progress 0.2.23

发布日期：2026-11-07 · [完整更新记录](https://github.com/carpe-horam/task-progress-codex/blob/v0.2.23/CHANGELOG.md)

- **执行轮次徽标**：把标题旁的“已重试 N 次”改为“第 N 轮执行”。悬浮说明轮次包含首次执行，不表示失败次数；任务当前状态仍单独显示。在线 HTN 任务树与旧版线性步骤保持一致。

## 安装或升级

```sh
codex plugin marketplace remove task-progress-codex
codex plugin marketplace add carpe-horam/task-progress-codex --ref v0.2.23
codex plugin add task-progress@task-progress-codex
```

首次安装可省略第一行。安装后重启 Codex，使新技能与服务端工具重新加载。现有任务数据保留。详见[安装文档](../installation.md)。

## 验证与边界

- `python3 -B tests/test_plugin_version.py`：通过，确认打包插件的 MCP 与面板版本由 manifest 正确注入。
- 本机未安装 Playwright，因此 `tests/test_retry_badge_app.cjs` 与 `tests/test_execution_lifecycle_app.cjs` 未能运行；本版本不声称动态浏览器 UI 回归通过。
- 本版本通过 `v0.2.23` 源码标签分发，不包含独立打包资产。
