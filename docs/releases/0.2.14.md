# Task Progress 0.2.14

发布日期：2026-11-03 · [完整更新记录](https://github.com/carpe-horam/task-progress-codex/blob/v0.2.14/CHANGELOG.md)

- 后续行动持续列出所有未解决叶任务；有效的 `continue`、`covered`、`obsolete` 盘点只提供复核上下文，不会让未解决任务静默消失或伪装成已解决。
- 重试或结果变化后，旧盘点绑定失效；新行动提示刷新任务状态、摘要、证据和依赖，并按情况重试或重规划。
- 会话恢复、阶段结束和交付前提醒回看未解决项。

## 安装或升级

```sh
codex plugin marketplace remove task-progress-codex
codex plugin marketplace add carpe-horam/task-progress-codex --ref v0.2.14
codex plugin add task-progress@task-progress-codex
```

安装后重启 Codex；现有任务数据无需迁移。首次安装可省略第一行。
