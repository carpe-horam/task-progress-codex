# Task Progress 0.3.1

重新从 **0.3.1** 开始发布，Cindy、Codex 和 DeepSeekRuntime 统一使用同一个版本号，后续同步递增。历史 release 和标签保留。

- 包含“等待主会话先完成”的可点击任务序号、定位连线、刷新保持和执行结束释放等待。
- 保留构建前的三端版本一致性校验。
- 本次仅调整发行版本及安装指引，任务行为与 0.2.61 相同。

## Codex 安装或升级

```sh
codex plugin marketplace remove task-progress-codex
codex plugin marketplace add carpe-horam/task-progress-codex --ref v0.3.1
codex plugin add task-progress@task-progress-codex
```

首次安装可省略第一行。启动新的 Codex 会话加载新版。Cindy 从同一标签构建，详见 [构建说明](../../plugins/task-progress/cindy/README.md)。

源码 release 不附独立安装包；安装与运行时加载分别验证。
