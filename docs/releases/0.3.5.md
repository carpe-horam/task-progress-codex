# Task Progress 0.3.5

Cindy、Codex 和 DeepSeekRuntime 统一版本 **0.3.5**。

- Cindy 场景的持续协作由 Lead 创建或复用 Orca Worker；Worker 在获派范围内按需使用宿主原生子智能体。两者的身份与回执分别记录。
- Lead 当前 Task Progress 任务树是主账本。现有服务端一次只允许一个运行中的主会话叶节点，因此并行 Orca Worker 在一个协调批次中记录，依赖在整个批次验收后放行。
- 主 Track Progress Skill 保留通用流程；Cindy 专属步骤见 [Orca Worker 协同](../../plugins/task-progress/skills/track-progress/references/cindy-orca-worker.md)。

本版更新三端清单与文档，不改变任务服务端状态或公开工具契约。GitHub Release 仅发布源码，不附独立安装资产；Cindy 插件从该标签生成并安装，安装回执与运行时加载需分别核实。
