# Task Progress 0.2.32

- Cindy 未绑定会话的上下文 Hook 提供开工指引，避免首次调用依赖已有绑定。继续任务须恢复准确身份，不因未绑定重复初始化。
- Hook 诊断区分事件收到、提示已发送、未发送原因和发送失败；发送成功仅表示投递回执，不保证模型已遵从。
- 任务树前置依赖改为可点击序号；点击自动展开目标分支，以流动连线指向并高亮前置任务。支持多依赖切换、重复点击或 Esc 收起、刷新保持定位。
- 连线按最终布局测量，修复说明栏换行后的端点偏移；支持浅色、深色、减少动态效果和窄屏触摸。
- 在 v0.2.31 基础上集成，保留任务工作区、详情和自动验收能力。Codex/DeepSeekRuntime 版本为 0.2.32，Cindy 清单版本为 0.2.59。

## 安装或升级

```sh
codex plugin marketplace remove task-progress-codex
codex plugin marketplace add carpe-horam/task-progress-codex --ref v0.2.32
codex plugin add task-progress@task-progress-codex
```

首次安装可省略第一行。重启 Codex 以加载新版；Cindy 通过其构建流程打包安装，详见 [Cindy 构建说明](../../plugins/task-progress/cindy/README.md)。

本次 release 为源码发行，不包含独立安装包。浏览器测试使用真实 Chrome 与隔离服务端，窄屏触摸为模拟事件，不代表物理手机或已安装 Cindy 的实机验证。
