# Task Progress 0.2.61

Cindy、Codex 和 DeepSeekRuntime 从本版统一使用 **0.2.61**，后续各端和 release tag 同步递增。历史版本不重写；本版高于已安装的 Cindy 0.2.60 和 Codex 0.2.33。

- 构建时检查三端清单版本，任意一个不一致都会在写入生成目录前失败。
- 保留“等待主会话先完成”的可点击序号、定位连线、刷新保持和执行结束释放等待。

## Codex 安装或升级

```sh
codex plugin marketplace remove task-progress-codex
codex plugin marketplace add carpe-horam/task-progress-codex --ref v0.2.61
codex plugin add task-progress@task-progress-codex
```

首次安装可省略第一行。启动新的 Codex 会话加载新版。Cindy 从同一标签构建，详见 [构建说明](../../plugins/task-progress/cindy/README.md)。

源码 release 不附独立安装包；安装状态与运行时加载分别验证。
