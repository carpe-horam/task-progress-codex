# Task Progress 0.2.11

发布日期：2026-11-02 · [完整更新记录](https://github.com/carpe-horam/task-progress-codex/blob/v0.2.11/CHANGELOG.md)

- 阶段盘点支持按阶段关联节点范围；决定绑定来源状态，未变化的继续决定可复用。
- 显式记录执行尝试之间的证据覆盖范围、理由与证据。原始失败、依赖和验收状态不被覆盖；来源变化后覆盖标记失效。
- 服务接口、主面板、历史视图、HTML 和 Excel 统一呈现已结束与已验收解决指标。
- 支持带审计记录的展示标题修订，并将图依赖就绪与外部前置条件分开呈现。

## 安装或升级

需要支持插件与 stdio MCP 的 Codex，以及 PATH 中可通过 `python` 启动的 Python 3。已有旧版本时：

```sh
codex plugin marketplace remove task-progress-codex
codex plugin marketplace add carpe-horam/task-progress-codex --ref v0.2.11
codex plugin add task-progress@task-progress-codex
```

首次安装可省略第一行。安装后重启 Codex，已打开的旧面板需重新打开。现有任务数据无需迁移。
