# Task Progress 0.2.17

发布日期：2026-11-05 · [完整更新记录](https://github.com/carpe-horam/task-progress-codex/blob/v0.2.17/CHANGELOG.md)

- **移除外部前置状态**：任务面板不再显示默认“外部前置未知”，删除人工声明接口 `set_external_prerequisite` 及外部前置状态投影。
- **精简报告与查询**：HTML、Excel 和面板移除外部前置专用字段、标签及人工记录详情；精简响应（`records_included=false`）继续省略旧 `external_prerequisite_reviews`，不增加历史记录负担。
- **保留任务依赖与审计**：图依赖、`ready` / `graph_ready` 判断继续生效。已有任务数据不迁移、不删除；`full` 与历史查询继续保留原有人工记录。旧专用 `record_kind=external_prerequisite_reviews` 查询入口随该功能移除。

## 安装或升级

```sh
codex plugin marketplace remove task-progress-codex
codex plugin marketplace add carpe-horam/task-progress-codex --ref v0.2.17
codex plugin add task-progress@task-progress-codex
```

首次安装可省略第一行。安装后重启 Codex 以加载新工具与插件代码；现有任务数据保留。详见[安装文档](../installation.md)。

## 验证与边界

- 后端：Python 3.12 下完整 unittest 通过，294 项，27.924 秒。
- 浏览器 UI/导出：8 个入口中 6 个通过。`test_export_river.cjs` 与 `test_history_loading_app.cjs` 在 `origin/main@050dd317` 的干净快照中复现相同失败（主会话叶任务守卫拒绝、历史 fixture 标题等待超时）；这两项没有算作通过，也未归因为本次改动。
- 未覆盖原生 Codex MCP Apps 宿主及真实 Excel 客户端验收；Linux/systemd 与 Windows Task Scheduler 的原生安装、登录恢复和异常重启仍需在对应系统验证。
- 本发布通过 `v0.2.17` 源码标签分发，不包含独立打包资产。
