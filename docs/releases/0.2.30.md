# Task Progress 0.2.30

- Cindy 0.1.140 及以上支持 `will-compose-context`、`did-task-state-changed`、`did-message-created` 和 `did-session-switched`。选用 Task Progress 的任务在 App 新轮次可获得只读参考资料；侧栏按已保存助手消息、任务状态或会话切换重读进度。
- 新增 `get_hook_diagnostics`，只返回当前 Cindy 会话的 Hook 投递计数、最后回执与侧栏重读结果。诊断不保存消息正文，不将 Hook 事件当作任务完成证据。
- Cindy 插件清单版本为 0.2.57，最低宿主版本为 0.1.140。Codex 和 DeepSeekRuntime 的插件版本同步为 0.2.30；本次没有改变它们的 Hook 覆盖范围。

`will-compose-context` 仅覆盖 App 正常发起的新轮次，且任务需在「任务插件」中选用 Task Progress。它只附加参考资料，不触发侧栏重读。Cindy 插件层仍没有 Codex `PreToolUse`、`PostToolUse` 或 `SubagentStart` 的等价回调。详细覆盖范围见 [Cindy Hook 说明](../../plugins/task-progress/cindy/HOOKS.md)。

## 安装或升级 Codex 插件

```sh
codex plugin marketplace remove task-progress-codex
codex plugin marketplace add carpe-horam/task-progress-codex --ref v0.2.30
codex plugin add task-progress@task-progress-codex
```

首次安装可省略第一行。安装后重启 Codex，使插件重新加载。Cindy 的打包和安装入口见 [Cindy 构建说明](../../plugins/task-progress/cindy/README.md)。

本 release 提供源码标签，不包含独立安装包。
