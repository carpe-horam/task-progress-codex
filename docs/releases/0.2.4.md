# Task Progress 0.2.4

发布日期：2026-10-30 · [完整更新记录](../../CHANGELOG.md) · [0.2.3 发布说明](0.2.3.md)

本版重新设计离线 HTML 导出：蜿蜒时间线突出计划轮次、重规划时间及原因；表格支持层级展开、统一时间刻度、六种浅色主题与十种时间条样式，默认节点轨迹。主任务默认收起子任务。报告区分整体跨度、重试间等待和累计执行时间，不将等待或并行子任务简单相加。

结束、收尾和归档时对缺失的任务时间边界执行保底补齐并标明来源；原有历史快照不会因为浏览或导出而改写。时间不完整的历史记录仍会说明其边界。

本版附带离线交互手册 `task-progress-0.2.4-guide.html`，内嵌本版界面和合成演示数据。

## 安装或升级

需要支持插件与 stdio MCP 的 Codex，以及 PATH 中可通过 `python` 启动的 Python 3。已有旧版本时先移除旧的 Marketplace 登记：

```sh
codex plugin marketplace remove task-progress-codex
codex plugin marketplace add carpe-horam/task-progress-codex --ref v0.2.4
codex plugin add task-progress@task-progress-codex
```

首次安装可省略第一行。安装后重启 Codex；已打开的旧面板需要重新打开。跨平台前提见[安装文档](../installation.md)。

## 验证范围与限制

本版使用隔离任务数据、真实后端和模拟宿主的 Chrome 回归验证导出与时间记录；这些验证不代表原生 Codex 桌面端的端到端验收。Linux、Windows 原生安装与升级仍未实测。历史数据中缺失的真实时间无法还原，保底边界不是实际执行时间。
