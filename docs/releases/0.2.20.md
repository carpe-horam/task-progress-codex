# Task Progress 0.2.20

发布日期：2026-11-06 · [完整更新记录](https://github.com/carpe-horam/task-progress-codex/blob/v0.2.20/CHANGELOG.md)

- **连续 owner 与显式配置来源**：紧密工作链优先复用同一 worker；模型、推理强度和分叉上下文分别记录 explicit、inherited 或 unknown。旧服务端能力协商与历史任务保持兼容。
- **逐项验收契约**：任务可固定版本化验收标准。执行者自检与主会话核验独立保存；resolved 结果需要每个 required 项有证据的 pass。
- **产物版本绑定**：实现提交、独立验证和主会话核验可以引用相同的 task/attempt、artifact 和版本，避免用旧报告验收已变更的产物。
- **界面与导出**：任务详情、离线 HTML 和 XLSX 显示契约、双方核验、产物版本和核验来源。

## 安装或升级

```sh
codex plugin marketplace remove task-progress-codex
codex plugin marketplace add carpe-horam/task-progress-codex --ref v0.2.20
codex plugin add task-progress@task-progress-codex
```

首次安装可省略第一行。安装后重启 Codex，使新服务端、工具、技能和 hook 被当前会话加载。现有任务数据保留。详见[安装文档](../installation.md)。

- 本地候选源码回归：`python3 -m unittest discover -s tests -v` 327 项通过（16.236 秒）；`test_plugin_version.py` 1 项通过；面板/HTML/XLSX 浏览器场景 12 项通过（15.233 秒）。`py_compile`、manifest JSON 解析及 `git diff --check` 通过。
- 该验证发生在 PR 之前，未覆盖 PR 合并 SHA 或远端发布资产；发布后仍需按该精确 SHA 回读并验证安装。
- 本版本没有启用 S3 自动派发绑定。hook 的 guided observation 不能替代真实宿主事件的精确因果关联；未提供 dispatch token 或等价父调用关联的宿主继续使用显式 `bind_task_agent`。
- 本地模拟宿主测试不代表原生 Codex、Linux 或 Windows 的完整端到端验证；本机安装和新服务加载须按发布验证记录单独核实。
- 已批准的 9 轮校准输入/oracle 和执行预算不是本版本的测试结果；未记录的实验保持未运行。
- 本版本通过 `v0.2.20` 源码标签分发，不包含独立打包资产。
