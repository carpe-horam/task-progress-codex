# Task Progress 0.2.9

发布日期：2026-11-01 · [完整更新记录](https://github.com/carpe-horam/task-progress-codex/blob/v0.2.9/CHANGELOG.md)

- 分开保存计划快照、原位修订、同一目标的重规划及独立新任务。快照不停止执行；原位修订限未开始且通过依赖与版本检查的分支。
- HTML 和 Excel 离线报告记录当前、历史及并行任务的快照与原位修订；Excel 对长原始记录分片保存。快照不计作计划轮次。
- 旧任务数据无需迁移。已有任务后初始化独立新目标需要显式填写 `task_relationship="independent"` 与 `new_task_reason`；同一目标的计划调整使用原位修订或重规划。

本版附带离线交互手册 `task-progress-0.2.9-guide.html`，使用本版界面和合成演示数据。

## 安装或升级

需要支持插件与 stdio MCP 的 Codex，以及 PATH 中可通过 `python` 启动的 Python 3。已有旧版本时：

```sh
codex plugin marketplace remove task-progress-codex
codex plugin marketplace add carpe-horam/task-progress-codex --ref v0.2.9
codex plugin add task-progress@task-progress-codex
```

首次安装可省略第一行。安装后重启 Codex；旧面板需重新打开。参见[安装文档](https://github.com/carpe-horam/task-progress-codex/blob/v0.2.9/docs/installation.md)。

## 验证范围

快照、原位修订、旧数据隔离副本和 Chrome 模拟宿主导出覆盖当前、历史、并行实例及长 Unicode 记录。后端全量回归中的旧时间边界断言和非 macOS 服务管理测试在原始基线亦失败；Linux、Windows 原生安装升级及原生 Codex 会话仍需单独验证。
