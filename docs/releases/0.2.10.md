# Task Progress 0.2.10

发布日期：2026-11-01 · [完整更新记录](https://github.com/carpe-horam/task-progress-codex/blob/v0.2.10/CHANGELOG.md)

- 历史原位修订按发生变化的字段展示修订前后内容；未变化字段不再挤占主要阅读区域。
- 完整修订前后记录仍可展开查看，便于审计大型排序和依赖快照。

## 安装或升级

需要支持插件与 stdio MCP 的 Codex，以及 PATH 中可通过 `python` 启动的 Python 3。已有旧版本时：

```sh
codex plugin marketplace remove task-progress-codex
codex plugin marketplace add carpe-horam/task-progress-codex --ref v0.2.10
codex plugin add task-progress@task-progress-codex
```

首次安装可省略第一行。安装后重启 Codex，已打开的旧面板需重新打开。现有任务数据无需迁移。
