# Task Progress 0.2.5

发布日期：2026-10-30 · [完整更新记录](../../CHANGELOG.md) · [0.2.4 发布说明](0.2.4.md)

- 主要阶段结束并完成必要复核后，提示主会话盘点未解决的任务，记录继续、过期或被覆盖的判断与原因。盘点绑定阶段尝试和状态版本，不自动改变已有任务结果；重试或前驱失效会保留提醒失效记录。
- 执行中追加问题时记录“追加”和原因，可指定尚未开始的既有后继，原子更新真实依赖及显示顺序。循环依赖和对已开始任务的静默改写会被拒绝。
- 盘点历史按需读取，旧客户端未提供原因时显示“未记录（旧调用）”。盘点提醒不强制阻止后续执行，Task Progress 不能代替主会话判断或控制其他宿主工具。

本版附带离线交互手册 `task-progress-0.2.5-guide.html`，使用本版界面和合成演示数据。

## 安装或升级

需要支持插件与 stdio MCP 的 Codex，以及 PATH 中可通过 `python` 启动的 Python 3。已有旧版本时：

```sh
codex plugin marketplace remove task-progress-codex
codex plugin marketplace add carpe-horam/task-progress-codex --ref v0.2.5
codex plugin add task-progress@task-progress-codex
```

首次安装可省略第一行。安装后重启 Codex；首次连接会更新本机后台服务，旧面板需重新打开。跨平台前提见[安装文档](../installation.md)。

## 验证范围

使用隔离任务数据的 Python 回归及真实 Chrome、模拟 MCP Apps 宿主验证；这些检查不代表原生 Codex 桌面和 Linux、Windows 安装的端到端验收。既有历史快照测试在未修改的 0.2.4 基线上也有失败，具体边界见交付说明。
