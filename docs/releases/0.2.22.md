# Task Progress 0.2.22

发布日期：2026-11-07 · [完整更新记录](https://github.com/carpe-horam/task-progress-codex/blob/v0.2.22/CHANGELOG.md)

- **等待任务导出修复**：HTML 和 XLSX 任务清单均保留 serial-waiting 任务正在等待的主会话任务 ID。
- **端到端回归**：以真实服务状态生成在线面板、离线 HTML 和 XLSX，验证等待标签、阻塞任务和导出列一致。

## 安装或升级

```sh
codex plugin marketplace remove task-progress-codex
codex plugin marketplace add carpe-horam/task-progress-codex --ref v0.2.22
codex plugin add task-progress@task-progress-codex
```

首次安装可省略第一行。安装后重启 Codex，使新技能与服务端工具重新加载。现有任务数据保留。详见[安装文档](../installation.md)。

## 验证与边界

- `python3 tests/test_main_session_serial.py`：3 项串行、并发与遗留记录回归通过。
- `tests/test_request_queue_app.cjs`：等待标签与阻塞任务详情等浏览器场景通过。
- `tests/test_export.cjs`：4 个 HTML/XLSX 场景通过，包括等待主会话字段与阻塞任务 ID。
- 上述浏览器测试使用模拟 MCP Apps 宿主及本机 Chrome/Playwright；不声称覆盖 Windows 原生宿主。
- 本版本通过 `v0.2.22` 源码标签分发，不包含独立打包资产。
