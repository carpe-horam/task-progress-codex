# Task Progress 0.2.25

发布日期：2026-11-10 · [完整更新记录](https://github.com/carpe-horam/task-progress-codex/blob/v0.2.25/CHANGELOG.md)

- `review_task_split` 支持可选的 `summary`，并将其保存到拆分复核记录。仍需提供唯一剩余结果、理由和证据。
- 评审前明确候选版本、基线和证据。独立核验提前规划，由不同的 agent 执行。工作区和输出隔离时，验证可以并行。
- 批量读取任务当前状态，只在下一步需要历史细节时补读记录。长时间 Dagu 运行优先使用事件等待，并按需读取日志。

## 安装或升级

```sh
codex plugin marketplace remove task-progress-codex
codex plugin marketplace add carpe-horam/task-progress-codex --ref v0.2.25
codex plugin add task-progress@task-progress-codex
```

首次安装可省略第一行。安装后重启 Codex，重新加载技能和工具。详见[安装文档](https://github.com/carpe-horam/task-progress-codex/blob/v0.2.25/docs/installation.md)。
