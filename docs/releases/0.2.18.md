# Task Progress 0.2.18

发布日期：2026-11-06 · [完整更新记录](https://github.com/carpe-horam/task-progress-codex/blob/v0.2.18/CHANGELOG.md)

- **任务创建时间与复核提醒**：新建任务节点记录 `created_at`。未解决任务创建超过 30 分钟后会作为“可能过期”候选提示；agent 更新任务状态时，回执同时汇总当前待复核任务、已失效结果和历史中仍未闭环的任务。提醒仅供复核，不会自动关闭或改写任务。
- **历史身份与重复提醒**：保留旧数据兼容，不从更新时间、开始/结束时间或归档时间推断创建时间。历史归档缺少实例 ID 时保持未知身份；已有验收、完整覆盖或当前有效处置的记录不再作为未处理事项反复提醒。
- **行动状态与用户界面**：有效标记为 `obsolete` / `covered` 的任务从可执行行动中排除，并显示处置原因和下一步；界面及 HTML/Excel 报告区分依赖阻塞、等待主会话与待处置盘点项。主任务仅在叶任务结束且无待复核提交时显示可进行综合验收。

## 安装或升级

```sh
codex plugin marketplace remove task-progress-codex
codex plugin marketplace add carpe-horam/task-progress-codex --ref v0.2.18
codex plugin add task-progress@task-progress-codex
```

首次安装可省略第一行。安装后重启 Codex 以加载新工具与插件代码；现有任务数据保留。详见[安装文档](../installation.md)。

## 验证与边界

- 30 分钟阈值是供 agent 复核的提示，不是任务失效事实或自动状态转换。
- 既有记录没有创建时间时按“未知”处理，不回填或猜测时间。
- 版本通过 `v0.2.18` 源码标签分发，不包含独立打包资产。
