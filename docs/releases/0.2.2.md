# Task Progress 0.2.2

发布日期：2026-10-30 · [本版 README](https://github.com/carpe-horam/task-progress-codex/blob/v0.2.2/README.md) · [完整更新记录](https://github.com/carpe-horam/task-progress-codex/blob/v0.2.2/CHANGELOG.md) · [0.2.1 发布说明](https://github.com/carpe-horam/task-progress-codex/blob/v0.2.1/docs/releases/0.2.1.md)

任务重试后，无需打开详情即可在任务标题旁看到“已重试 N 次”。首次执行不显示标记，任务结束后标记保留；当前状态仍独立显示。线性步骤同样支持此提示，分组综合验收不会误标为执行重试。

本版附带离线交互手册 `task-progress-0.2.2-guide.html`，内嵌本版界面与合成演示数据。

## 首次安装

需要支持插件与 stdio MCP 的 Codex 客户端，以及 Codex 进程 PATH 中可通过 `python` 启动的 Python 3。安装后重启 Codex：

```sh
codex plugin marketplace add carpe-horam/task-progress-codex --ref v0.2.2
codex plugin add task-progress@task-progress-codex
```

首次连接会自动安装或更新共享后台服务。macOS 使用 LaunchAgent，Linux 需要可用的 systemd 用户会话，Windows 使用当前登录用户的任务计划程序。详见[安装与服务管理](https://github.com/carpe-horam/task-progress-codex/blob/v0.2.2/docs/installation.md)。

## 从旧版本升级

```sh
codex plugin marketplace upgrade task-progress-codex
codex plugin add task-progress@task-progress-codex
```

重启 Codex 以加载新版插件；首次连接会自动更新共享服务，任务数据无需迁移。已打开的旧界面需要重新打开才能加载新版界面。

## 验证与限制

本版通过隔离 Python 服务与 Chrome 模拟 MCP Apps 宿主的定向界面检查及交互回归；这不等同于真实 Codex 宿主端到端验收。Linux 与 Windows 的原生安装、登录恢复和升级尚未在对应平台实测。
