# Task Progress 0.2.2

0.2.2 将共享后台服务的安装与升级并入插件连接流程。macOS 使用 LaunchAgent，Linux 使用 systemd 用户服务，Windows 使用当前用户的任务计划程序。首次安装仍只需添加 Marketplace 并安装插件；用户不再手动运行缓存目录中的 `service_manager.py` 命令。

## 平台前提与验证范围

需要支持插件与 stdio MCP 的 Codex，以及 Codex 进程 PATH 中可通过 `python` 启动的 Python 3。Linux 自动管理依赖 systemd 用户会话和 D-Bus；Windows 使用当前用户的交互式登录令牌，注销后服务停止。Windows 凭据文件访问由用户配置文件 ACL 管理，本版本没有单独重设 ACL。

本次源码实现经过静态检查和独立审阅；Linux systemd 与 Windows Task Scheduler 的安装、登录恢复和升级尚未在原生平台实测。已有 v0.2.1 标签和发布内容不变。

## 安装

```sh
codex plugin marketplace add carpe-horam/task-progress-codex --ref v0.2.2
codex plugin add task-progress@task-progress-codex
```

安装后重启 Codex。首次连接会安装或升级服务。需要 Python 3 的 `python` 命令在 Codex 的 PATH 中可用。

## 升级

```sh
codex plugin marketplace upgrade task-progress-codex
codex plugin add task-progress@task-progress-codex
```

随后重启 Codex。Marketplace 刷新不会更新已安装插件；新 MCP 连接会更新后台服务版本。任务数据保存在独立的用户缓存中，升级不会删除它。

各平台系统服务前提、故障排查和手动管理命令见[安装与服务管理](installation.md)。
