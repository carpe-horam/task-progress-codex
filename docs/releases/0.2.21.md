# Task Progress 0.2.21

发布日期：2026-11-07 · [完整更新记录](https://github.com/carpe-horam/task-progress-codex/blob/v0.2.21/CHANGELOG.md)

- **旧服务能力回退**：派发指南示例明确以 `protocol_capabilities` 门控 `model_source`、`reasoning_effort_source` 与 `fork_turns`。旧服务未公布能力时，沿用它接受的旧字段，并保留 agent 绑定、结果提交和主会话独立复核。
- **兼容性复核**：当前代码的旧 in-flight、旧客户端与历史数据显示回归通过；v0.2.19 精确源码在临时服务端 API 探针中拒绝不支持的 `fork_turns="all"` 且不改变状态，使用兼容 payload 可启动。

## 安装或升级

```sh
codex plugin marketplace remove task-progress-codex
codex plugin marketplace add carpe-horam/task-progress-codex --ref v0.2.21
codex plugin add task-progress@task-progress-codex
```

首次安装可省略第一行。安装后重启 Codex，使新技能与服务端工具重新加载。现有任务数据保留。详见[安装文档](../installation.md)。

## 验证与边界

- `python3 -m unittest tests.test_responsibility_contract tests.test_delegation_policy -v`：40 项通过。
- `tests/test_responsibility_app.cjs` 使用本机现有 Playwright/Chrome 依赖执行：12 个面板/HTML/XLSX 场景通过。
- v0.2.19 源码 API 探针：能力字段缺失；`fork_turns="all"` 被拒绝且 `state_revision` 不变；省略新字段的旧兼容启动请求成功。
- 模拟宿主与临时服务端导入不代表 Codex 原生新旧版本并列加载；Windows 未验证。
- 本版本通过 `v0.2.21` 源码标签分发，不包含独立打包资产。
