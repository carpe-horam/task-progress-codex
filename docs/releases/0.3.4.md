# Task Progress 0.3.4

Cindy、Codex 和 DeepSeekRuntime 统一版本 **0.3.4**。

- Cindy 收到确认的空进度读取时不再占用会话映射，避免首次任务初始化与空读竞态导致面板仍显示空状态。
- 未绑定会话的开工提示明确区分 Hook 诊断与任务初始化，要求多阶段任务在编辑、运行命令或委派前提交初始计划和验收条件。
- `get_hook_diagnostics` 分开展示 Hook 投递与任务会话/实例绑定状态。

## Codex 安装或升级

```sh
codex plugin marketplace remove task-progress-codex
codex plugin marketplace add carpe-horam/task-progress-codex --ref v0.3.4
codex plugin add task-progress@task-progress-codex
```

首次安装可省略第一行。启动新的 Codex 会话加载新版。Cindy 从同一标签构建，详见 [构建说明](../../plugins/task-progress/cindy/README.md)。

源码 release 不附独立安装包；安装与运行时加载分别验证。
