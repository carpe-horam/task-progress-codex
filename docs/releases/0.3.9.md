# Task Progress 0.3.9

Cindy、Codex 和 DeepSeekRuntime 统一版本 **0.3.9**。

- 新增 macOS 原生任务进度浮窗，默认黑色并置顶；`/open-progress-widget` 默认使用当前会话的 Task Progress 身份定位任务。
- 左侧集中任务列表、搜索筛选、查看模式、置顶及主题控制；右侧复用原有 `app.html`，保留任务树、矩阵、详情、历史和报告生成。
- 支持单任务与最多8项平铺，只有选中卡片可滚动和操作内部页面；侧栏默认展开，缩窄窗口不自动折叠；任务标题只显示一次。
- 只读查看同一本机服务的当前、并行及历史实例，不切换正在执行的任务。原生导出保存 Excel 和 HTML，关闭浮窗不停止后台工作。
- Cindy Lead 与 Worker 双向通信默认显式使用 `delivery="steer"`，核对投递回执，排队不算即时送达；替换或停止任务仍使用中断机制。
- 规划时仅有一个工作包则直接列出顶层任务，避免 `1 → 1-1、1-2` 的冗余包裹层。

## 使用

在支持 Skill 的会话中运行 `/open-progress-widget`，或从源码目录执行：

```sh
python3 plugins/task-progress/progress_widget.py --ensure-service
```

原生浮窗目前支持有桌面的 macOS，需要 Python 3 与 Xcode Command Line Tools；首次编译后缓存。不带定位参数的终端命令显示任务列表；Agent Skill 会从本会话成功回执恢复真实身份并传入定位参数。仅汇集同一本机 Task Progress 服务的数据，不自动读取其他独立账本或 Cindy KV。

本版为源码 release，没有附加安装资产。Cindy 插件从该标签按 [构建说明](../../plugins/task-progress/cindy/README.md) 生成。Codex 升级时将 Marketplace 固定到 `v0.3.9`，重新安装插件并重启；任务数据保留。

402 项 Python 测试、浮窗真实服务界面回归、共享 HTTP 面板回归和 Cindy 面板回归通过；Cindy Forge 打包后核对了新 Skill、原生脚本和运行资产。macOS 开发验收另外确认了实际窗口创建、置顶/缩放、手动侧栏和 Excel/HTML 落盘。发布不代表已完成 Linux、Windows 或其他远程桌面环境的原生浮窗支持。
