# Task Progress 0.2.33

- “等待主会话先完成”中的任务名称改为可点击序号，支持定位连线和目标高亮。
- 当前执行任务切换后同步更新序号；执行结束后清除串行等待提示和定位。普通前置依赖仍按自身解决条件处理。
- 覆盖目标位于上方/下方、折叠分支、刷新、320/430 px 触摸，以及执行以 open 结束仍释放主会话占用。
- Codex / DeepSeekRuntime 版本为 0.2.33；Cindy 插件清单版本为 0.2.60。

## Codex 安装或升级

```sh
codex plugin marketplace remove task-progress-codex
codex plugin marketplace add carpe-horam/task-progress-codex --ref v0.2.33
codex plugin add task-progress@task-progress-codex
```

首次安装可省略第一行。启动新的 Codex 会话以加载插件。Cindy 从此源码标签构建安装，详见 [Cindy 构建说明](../../plugins/task-progress/cindy/README.md)。

源码 release 不附独立安装包。安装完成、运行时加载及界面实测是分别核实的结果。
