# Task Progress 0.2.26

发布日期：2026-11-12 · [完整更新记录](../../CHANGELOG.md)

- 拆分复核支持通过 `execution_id` 核对当前执行，可继续提交和保存 `summary`。
- 恢复会话时复用已确认的实例身份。实例不匹配、阶段盘点和验收提交失败时，回执提供相应的恢复路径或需补充的字段。
- 启动前识别叶任务上无法满足的独立核验要求。独立核验契约放在同时包含目标任务与核验任务的分组上。
- 新增 DeepSeekRuntime bundle，与 Codex 插件共享任务服务、界面和技能源码。

## 安装或升级 Codex 插件

```sh
codex plugin marketplace remove task-progress-codex
codex plugin marketplace add carpe-horam/task-progress-codex --ref v0.2.26
codex plugin add task-progress@task-progress-codex
```

首次安装可省略第一行。安装后重启 Codex，重新加载技能和工具。DeepSeekRuntime 安装步骤见[安装文档](../installation.md)。本版本通过 `v0.2.26` 源码标签分发。

## 验证

- 367 项后端回归通过，包含双宿主打包、拆分复核、阶段盘点和恢复指引相关行为。
- Chrome 中通过执行生命周期回归，覆盖自动收尾、重试标记和离线回执。
