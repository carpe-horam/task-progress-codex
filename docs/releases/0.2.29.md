# Task Progress 0.2.29

- 追加同一阶段的工作时，可沿用已有父任务。初始化或追加计划时，可一次创建新的父任务及其子任务。
- 共享进度面板支持按状态筛选。默认折叠非活跃分组，随执行和待验收状态展开相应分支，刷新时保留手动展开或折叠。
- Codex 和 DeepSeekRuntime 的插件版本同步为 0.2.29。Cindy 插件清单版本为 0.2.56。

## 安装或升级 Codex 插件

```sh
codex plugin marketplace remove task-progress-codex
codex plugin marketplace add carpe-horam/task-progress-codex --ref v0.2.29
codex plugin add task-progress@task-progress-codex
```

首次安装可省略第一行。安装后重启 Codex，使插件重新加载。Cindy 的打包和安装入口见 [Cindy 构建说明](../../plugins/task-progress/cindy/README.md)。

本 release 提供源码标签，不包含独立安装包。
