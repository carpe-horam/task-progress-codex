# Task Progress 0.2.13

发布日期：2026-11-03 · [完整更新记录](https://github.com/carpe-horam/task-progress-codex/blob/v0.2.13/CHANGELOG.md)

- 原位计划修订自动保留修订前后的完整任务树；历史计划中可分别展开查看修订前和修订后结构。
- 继续展示已有的字段差异和完整修订记录。旧修订没有完整树快照时会明确提示，不会从当前计划推造历史状态。
- 旧任务数据无需迁移。

## 安装或升级

需要支持插件与 stdio MCP 的 Codex，以及 PATH 中可通过 `python` 启动的 Python 3。已有旧版本时：

```sh
codex plugin marketplace remove task-progress-codex
codex plugin marketplace add carpe-horam/task-progress-codex --ref v0.2.13
codex plugin add task-progress@task-progress-codex
```

首次安装可省略第一行。安装后重启 Codex，已打开的旧面板需重新打开。现有任务数据无需迁移。
