# Task Progress 0.2.24

发布日期：2026-11-09 · [完整更新记录](https://github.com/carpe-horam/task-progress-codex/blob/v0.2.24/CHANGELOG.md)

- **减少 Task Progress 调用错误**：track-progress skill 规定所有会话、实例、任务和 attempt ID 都只能逐字复用工具回执或已确认记录中的值；缺少身份时不猜、不轮换，错误后根据确切错误更正一次，仍失败就停止该路径。
- **减少冗余读取**：查询指引按恢复、计划、验收、历史和写后核对选择最小视图；成功写回执后仅在下一步确实依赖详细状态时查询，避免无变化重复读取和轮询。

## 安装或升级

```sh
codex plugin marketplace remove task-progress-codex
codex plugin marketplace add carpe-horam/task-progress-codex --ref v0.2.24
codex plugin add task-progress@task-progress-codex
```

首次安装可省略第一行。安装后重启 Codex，使新技能与服务端工具重新加载。现有任务数据保留。详见[安装文档](../installation.md)。
