# Task Progress 0.2.8

发布日期：2026-10-31 · [完整更新记录](https://github.com/carpe-horam/task-progress-codex/blob/v0.2.8/CHANGELOG.md)

- 叶任务连续两次未解决后再次重试，工具回执提供最近两次原因和摘要，提醒 agent 判断问题是否相同或相关，并按需评估优化或重新规划。提醒不阻止重试，也不自动修改任务。
- 失败或开放结果可以记录明确的失败原因；缺少原因时不推断。判断依赖 agent 和尝试上下文，不依赖文本精确匹配。

本版附带离线交互手册 `task-progress-0.2.8-guide.html`，使用本版界面和合成演示数据。

## 安装或升级

需要支持插件与 stdio MCP 的 Codex，以及 PATH 中可通过 `python` 启动的 Python 3。已有旧版本时：

```sh
codex plugin marketplace remove task-progress-codex
codex plugin marketplace add carpe-horam/task-progress-codex --ref v0.2.8
codex plugin add task-progress@task-progress-codex
```

首次安装可省略第一行。安装后重启 Codex；旧面板需重新打开。跨平台前提见[安装文档](https://github.com/carpe-horam/task-progress-codex/blob/v0.2.8/docs/installation.md)。

## 验证范围

重试记录和责任协议测试通过（74 项）。选择性查询测试 8 项中 1 项失败：归档会补齐旧记录缺失的时间边界，测试仍要求与原始夹具完全相同；该失败在 0.2.7 基线上同样复现。离线手册使用模拟宿主与演示数据；这些检查不代表原生 Codex 桌面或 Linux、Windows 安装升级的端到端验收。
