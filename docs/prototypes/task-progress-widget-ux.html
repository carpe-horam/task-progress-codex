关闭浮窗不影响任务执行

一个浮窗，查看所有任务。

任务来自本机 Task Progress 服务。查看和切换任务不会改变执行中的任务，关闭控件也不会停止执行。

  • 单任务：点击左侧任务，查看完整任务树和详情。
  • 平铺：一键选入最多 8 个未完成任务，在左侧勾选调整。
  • 平铺时先点击选中卡片，再滚动内部内容；未选中卡片上的滚轮用于浏览整个平铺区。右上角可放大或移出。
  • 搜索、筛选与明暗主题均可操作；右侧直接复用现有 app.html 的任务树、详情、历史和导出。
  • 侧栏只由用户手动收起或展开，缩小窗口不会自动折叠。
  • 置顶和窗口大小由原生控件管理。
